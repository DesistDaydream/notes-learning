# 概述

> 参考：

> - [Wiki, Cyber range](https://en.wikipedia.org/wiki/Cyber_range)

**Vulnerable** 在中文环境那种可以称为 靶场、靶站、etc. ，用来描述在安全测试过程中充当被攻击或者主动检测的目标。

> 英文中好像没有一个明确的词儿可以和 靶场、靶站 相对应，这个词是从 Vulhub 项目中找到的。
