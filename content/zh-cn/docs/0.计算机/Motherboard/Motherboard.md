# 概述

> 参考：
>
> - [Wiki, Motherboard](https://en.wikipedia.org/wiki/Motherboard)

**Motherboard(主板)** 是通用计算机和其他可扩展系统中的 **[Printed circuit board](https://en.wikipedia.org/wiki/Printed_circuit_board)(印刷电路板，简称 PCB)**。主板用于承载一套系统中许多关键电子组件之间的通信，例如 [CPU](/docs/0.计算机/CPU/CPU.md)、[Memory](/docs/0.计算机/Memory/Memory.md)，并为其他外围设备提供连接器。与 **[Backplane](https://en.wikipedia.org/wiki/Backplane)(背板)** 不同，主板通常包含重要的子系统，例如中央处理器、芯片组的输入/输出和内存控制器、接口连接器以及其他为通用应用集成的组件。

> 主板还有很多其他英文单词：**mainboard**, **main** **circuit board**, **mb**, **mboard**, **backplane board**, **base board**, **system board**, **logic board** (only in Apple computers) or **mobo**

主板特指具有扩展能力的 PCB。顾名思义，这块板通常被称为连接到它的所有组件的“母板”，通常包括外围设备、接口卡和子板：声卡、视频卡、网卡、主机总线适配器、电视调谐器卡, IEEE 1394 卡；以及各种其他自定义组件。

类似地，术语主板是指具有单板且没有额外扩展或能力的设备，例如激光打印机、电视机、洗衣机、手机和其他扩展能力有限的嵌入式系统中的控制板。

# 芯片组

**Chipset(芯片组)** 是指集成在一个或多个集成电路上的电子元件的集合，用于管理 CPU、Memory、[Peripheral](/docs/0.计算机/Peripheral/Peripheral.md) 之间的数据流。

> [!Attention] 有时候，不同类型的芯片组只能搭配特定的 CPU
> e.g. Intel 的 B760 只能支持 Core i 系列（e.g. i3, i5, i7, i7），而 B860 只能支持 2023 年之后出的 Core Ultra 系列（e.g. U5, U7, U9）

在 2003 年之前，CPU 与 主内存 或 扩展设备（例如显卡） （无论是AGP 、PCI还是集成在主板上的显卡 ）之间的任何交互都由北桥芯片代表处理器直接控制。这使得处理器性能高度依赖于系统芯片组，尤其是北桥的内存性能以及将信息传回处理器的能力。然而，2003 年 AMD 推出的 Athlon 64 系列处理器改变了这一现状。Athlon 64 标志着集成内存控制器被集成到处理器本身，从而使处理器能够直接访问和处理内存，不再需要传统的北桥芯片。英特尔在 2008 年也推出了 Core i 系列 CPU 和 X58 平台，实现了类似的功能。

在 2003 年之后的处理器中，集成度进一步提高，这主要是通过将系统的主 PCIe 控制器和集成显卡直接集成到 CPU 上实现的。随着处理器处理的功能越来越少，芯片组厂商将剩余的北桥和南桥功能压缩到单个芯片中。英特尔的版本称为 **Platform Controller Hub(平台控制器中心，简称 PCH)**，而 AMD 的版本称为 **Fusion Controller Hub(融合控制中心，简称 FCH)**。PCH, FCH, etc. 仍然被统称为芯片组。它相当于一个增强型南桥，用于处理剩余的外围设备——因为传统的北桥功能，例如内存控制器、扩展总线（PCIe）接口甚至板载视频控制器，都集成到了 CPU 芯片本身（尽管芯片组通常包含辅助 PCIe 连接）。

# 芯片厂家

## 芯片命名规则

Intel, AMD 等厂家的芯片命名主要是指芯片组。

**Intel 芯片组**

|        | 产品定位（字母）    | 代系（百位数字） | 性能等级        |
| ------ | ----------- | -------- | ----------- |
| **描述** | 字母          | 一位数字     | 两位数字        |
| **示例** | H/B/X/Z/W/Q | 5/6/7/8  | 10/60/70/90 |

**产品定位**

- H 主打低价
- B 中档
- Z 和 X 系列是高端芯片
- 另外还有 W（工作站，如 W680）、Q（商用/vPro，不超频）。X 是 HEDT（高端桌面发烧平台），Z 是主流平台里可超频的，H/B 不可以超频，Q 和 W 不可超频但对应商用/工作站特性。

**代系** # 代表芯片组世代，通常与 插槽/CPU代数 绑定：

- 600系列 → LGA1700，配12代酷睿
- 700系列 → LGA1700（插槽不变），配13/14代酷睿
- 800系列 → LGA1851（新插槽），配酷睿Ultra 200S

**性能等级** # 数字越大定位越高

- X10 最低（H610/H810）
- X60 中端（B660/B760/B860）
- X90 旗舰（Z690/Z790/Z890）

# USB

**Universal Serial Bus(通用串行总线，简称 USB)** 是一种用于连接计算机和外部设备的通用接口标准。USB 接口已经成为现代电子设备中最为常用的接口之一，可用于连接键盘、鼠标、打印机、扫描仪、移动硬盘、闪存驱动器、智能手机等各种设备。

# 外形规格

> 参考：
>
> - [Wiki, Motherboard form factor](https://en.wikipedia.org/wiki/Motherboard_form_factor)
> - https://www.xpg.com/rs/knowledgehub/pc-chassis/105

**Form factor(外形规格)** 指主板的具体规格，包括 尺寸、电源类型、安装孔位置、背板端口数量、etc. 。

| 规格简称  | 全称                           | 尺寸           | 描述              |
| ----- | ---------------------------- | ------------ | --------------- |
| ATX   | Advanced Technology Extended | 305 × 244 mm | 最常用的尺寸规格        |
| mATX  | MicroATX                     | 244 x 244 mm | 比 ATX 小         |
| E-ATX | Extended ATX                 | 305 x 330 mm | 比 ATX 大         |
| ITX   | TODO                         | 170 × 170 mm | 各种 XX-ITX 通常都很小 |
| etc.  |                              |              |                 |

尺寸标准由 英特尔（ATX/mATX）或 VIA（ITX系列）等这类平台/芯片厂商最初发布，后来变成整个行业公认的公开规范，此后所有主板厂商（华硕/技嘉/微星等）都是**遵循**这套尺寸和螺丝孔位标准去设计自己的板子

# 主板厂商

御三家：华硕、微星、技嘉

### 命名规则

主板厂家命名通常以芯片厂家的芯片组作为主要字段

|        | 厂商产品线/系列        | 芯片组            | 板型           | 系列内的产品定位    | 功能特性标签           | 内存/版本后缀         |
| ------ | --------------- | -------------- | ------------ | ----------- | ---------------- | --------------- |
| **描述** | 字符串，厂商自定位       | 芯片厂定义，厂商原样嵌入   | 字母           | 字符串         | 字符串              | 字符串             |
| **示例** | ROG/GAMING/etc. | H610/B860/etc. | 无/M/ITX/etc. | 无/K/-A/etc. | WIFI/GAMING/etc. | D4/D5/R2.0/etc. |

**厂商产品线**

- PRIME / TUF GAMING / ROG STRIX / ProArt / AYW 技嘉产品线
- PRO/MAG/MPG/MEG 微星产品线
- (无)/GAMING/AORUS 技嘉产品线

**芯片组** # 详见 [芯片命名规则](#芯片命名规则)

**板型** # 详见 [外形规格](#外形规格)，只不过主板厂商在命名中通常只使用单字母表示板型

- 无 #
- M # mATX

**功能特性标签** # 设计比较个性，各种厂商通常有自己一套逻辑，不过一般都可以见文智意

华硕命名示例

- **PRIME B760M-K D4**
    - `PRIME`(厂商系列，定位入门/主流) + `B760`(Intel芯片组) + `M`(mATX 板型) + `K`(PRIME 系列内的分档字母，入门款) + `D4`(支持 DDR4)
- **TUF GAMING B760M-PLUS WIFI D4**
    - `TUF GAMING`(厂商系列，军规用料/中端游戏定位) + `B760`(芯片组) + `M`(mATX) + `-PLUS`(该系列的分档字母/词) + `WIFI`(功能标签，内置 WiFi) + `D4`(DDR4)
- **ROG STRIX B760-A GAMING WIFI**
    - `ROG STRIX`(厂商系列，高端游戏定位) + `B760`(芯片组) + 无 M 说明是 ATX 大板 + `-A`(分档) + `GAMING WIFI`(功能标签)
- **B760M-AYW WIFI D4**
    - 无 PRIME/TUF 等系列前缀，`AYW` 本身既充当"系列昵称"又充当"分档标识"（国内特供） + `B760`(芯片组) + `M`(mATX) + `WIFI`(功能标签) + `D4`(DDR4)

> 总结：Intel, AMD, etc. 把芯片组卖给主板厂商（华硕、技嘉、微星、华擎、etc.），各厂商拿到芯片组规格后自己设计 PCB、布线、供电、BIOS、附加功能，再贴自己的品牌和型号名（比如"PRIME H610M-A"是华硕的命名，技嘉可能叫"H610M S2H"）
