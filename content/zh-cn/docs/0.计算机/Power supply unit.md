**Power supply unit(电源单元)** 将市电交流电，转换为低压稳压的直流电，为 [Computer](/docs/0.计算机/Computer.md) 内部组件供电。

> [!Note] 由于它是机箱内唯一直接接市电的部件，因此相对市电它是负载，相对机箱内的其他组件它才是电源，这与 [Power supply](/docs/0.计算机/Power%20supply.md) 中对电源/负载的讨论一致。

# 电气指标

> [!Quote] [电气工程](https://en.wikipedia.org/wiki/Electrical_engineering) 是一门工程学科，主要研究、设计和应用使用电力、电子和电磁技术的设备、装置和系统。它在19世纪下半叶随着电报、电话以及电力生产、输送和使用的商业化而兴起，成为一门独立的职业

**转化率** # 也称为“输出转化效率”。$\frac{直流输出}{交流输入}=转换率$。假设输出需要 300W，在 80% 转化率的情况下，需要 375W 输入，其中损耗的 75W 转换为热量，需要通过散热方式排除。

> [!tip] 不同的负载下，转化率不同
> 通常呈抛物线状态，一般情况，在 40% - 50% 的负载下，转化率最高。前期转化率提升快，后面负载率下降得慢

**功率因数** # 功率因数越接近 1，有功功率的占比越高。功率因数反应了视在功率的真正利用率。

**80 PLUS** 认证 # 在不同负载下，功率因数 和 转化率 的指标。分为 115V 和 230V 两种规则。

| 负载\类型 | 白牌           | Bronze(铜牌)   | Silver(银牌)   | Gold(金牌)     | Platinum(白金牌) | Titanium(钛金牌) |
| ----- | ------------ | ------------ | ------------ | ------------ | ------------- | ------------- |
| 10%   | ——           | ——           | ——           | ——           | ——            | 90%           |
| 20%   | 80%          | 82%          | 85%          | 87%          | 90%           | 90% / PF 0.95 |
| 50%   | 80%          | 85% / PF 0.9 | 88% / PF 0.9 | 90% / PF 0.9 | 92% / PF 0.95 | 94%           |
| 100%  | 80% / PF 0.9 | 82%          | 85%          | 87%          | 89%           | 90%           |

> [!Note] 80 PLUS 表中的 XX/YY，XX 表示转化率；YY 表示功率因数

总结一下：80 PLUS 只有转化率的指标（转化率对电费的影响在 5 年的计算范围中，最多大概不超过 500 元）。其他的诸如 接口数量、线材长度、工作温度、输出波纹、电压偏离、保持时间、交叉负载、过载保护、etc. 指标都没有作为评测指标。高转化率通常是高品质元器件和高级方案所带来的附加增益效果，因为一般用料更好的，转化率通常也越好。

## 如何选择合适的电源功率？

**Thermal design power(散热设计功耗，简称 TDP)** 有时候作为厂家说明中的“基础功耗“，但是 TDP 对消费者来说没有太多参考价值[^电源1][^电源2]（因为睿频等原因，CPU 跑满的话，实际功耗可能是 TDP 标的 2 倍还多）。

通过搜索引擎搜索要买的 CPU 的 FPU 与 GPU 的 Furmark，找到各种评测出来的功耗。然后再留一些功耗余量（尽量不然电源满载），让电源的额定功率达到最高功耗的 120% 即可。

> [!Quote]
> FPU 是 AIDA64 软件内，对 CPU 系统稳定性测试的一项，在这个测试中，可以让 CPU 跑满，然后通过传感器看到 CPU 的实时功耗
>
> Furmark 是 GPU 测试软件（也称”甜甜圈“），搭配 GPU-Z 软件读取 GPU 的实时功耗。

另外，比较简单直接的可以参考 “装机小助手” 小程序中描述：建议选择 额定功率 大于 预估功耗 300W 以上为佳。e.g. 预估功耗约 350W，建议选择 650W 以上的电源。

# 外形规格

电源的 **Form factor(外形规格)** 有独立于主板的一整套规范（Intel《Power Supply Design Guide for Desktop Platform Form Factors》），与主板的 ATX / mATX / ITX 不是同一张表，只是 ATX、SFX 这类简称重名。规范规定电源的三维尺寸、风扇朝向与接口定义，从而决定它能装进哪种机箱。

| 规格       | 全称                                   | 尺寸(W × H × D)        | 描述                                     |
| -------- | ------------------------------------ | -------------------- | -------------------------------------- |
| ATX      | Advanced Technology eXtended，俗称 PS/2 | 150 × 86 × 140 mm    | 最常用，从入门到大功率都覆盖                         |
| SFX      | Small Form Factor                    | 125 × 63.5 × 100 mm  | 小机箱，多为 8cm 风扇，同瓦数比 ATX 贵               |
| SFX-L    | SFX-Large                            | 125 × 63.5 × 130 mm  | SFX 加长版，可装 12cm 风扇；行业事实规范，非 Intel 原始规范 |
| TFX      | Thin Form Factor                     | 85 × 65 × 175 mm     | 品牌机窄机箱，细长条                             |
| Flex ATX | FlexATX                              | 81.5 × 40.5 × 150 mm | 1U 机箱、迷你主机，小风扇噪音大                      |
| etc.     |                                      |                      | 还有 CFX 等更少见的规格。                        |

服务器与工业侧不走这套体系：

- **机架冗余电源** # 1U/2U 电源模块（CRPS 规范，约 73.5 × 40 × 265 mm），靠金手指插在背板上，支持热插拔与 N+1 冗余，可跨品牌替换
- **通信电源** # 与机架冗余电源同一思路：整流模块 + 配电 + 监控，按需加模块扩容。输出是 -48V 直流，不是 ATX 那套 12V/5V/3.3V
- **工业电源** # 开放式框架(open frame)、导轨式(DIN rail)
- **分离式** # 外置适配器（砖头）+ DC-ATX 直插模块，市电在机箱外转换，机箱内只留一块 DC-DC 板

> [!Attention] 装机时以机箱标注支持的电源规格为准；主板的外形规格只决定机箱，不决定电源。

# 模组化电源

> 参考：
>
> - [Wiki, Power supply unit(computer) - Modular power supplies](https://en.wikipedia.org/wiki/Power_supply_unit_(computer)#Modular_power_supplies)

**Modular power(模块化电源)** 指输出线材与电源本体之间是否可插拔，与电源本身的电气素质无关，只影响理线与换线。

| 类型 | 特征 | 取舍 |
| --- | --- | --- |
| 非模组 Non-modular | 线材全部直出焊死 | 最便宜，接触点最少 |
| 半模组 Semi-modular | 24pin 主板与 CPU 供电直出，其余可插拔 | 成本与理线折中 |
| 全模组 Fully modular | 全部可插拔，含 24pin | 理线最自由，可换定制线 |

**接口是不是统一标准？** 分设备侧与电源侧，结论完全不同。

- **设备侧是标准** # 24-pin ATX、4+4 EPS12V(CPU)、6+2 PCIe、SATA、Molex、12V-2x6(12VHPWR)，都写在 Intel ATX 规范里，任何品牌的线插上都能用
- **电源侧不是标准** # 模组盘上的插座排布与针脚定义由各家自定，ATX 规范未作规定。同样是 8-pin，A 家可能是 CPU 供电，B 家可能是 PCIe，+12V 与 GND 的顺序还可能不同；兼容性只能按「品牌 + 系列/代际」划分（e.g. Corsair Type 3 与 Type 4 不通用，各家定制线都要指定型号）
- **服务器侧是标准** # CRPS 的金手指与机箱背板接口由规范定义，可跨品牌热插拔

> [!Attention] 模组线不要跨品牌混用。外观相近、防呆很弱，插错等于把 12V 灌进本该接 5V/3.3V 的针脚，会烧硬盘与主板。

## 模组线

通常情况下，全模组化的电源通常要包含 4 类模组线：

| 线材     | 规格                                  | 数量                        |
| ------ | ----------------------------------- | ------------------------- |
| 主板供电   | 24-pin ATX（20+4 可拆分，兼容老主板）          | 1 条必插                     |
| CPU 供电 | 4+4 / 8-pin EPS12V                  | 1 条，中高端主板要 2 条（8+8 或 8+4） |
| 显卡供电   | 6+2 / 8-pin PCIe；新卡是 16-pin 12V-2x6 | 按显卡，1~4 条                 |
| 存储供电   | SATA 电源                             | 每块 2.5"/3.5" 盘一条，一般 2~4 条 |
| etc.   |                                     |                           |
